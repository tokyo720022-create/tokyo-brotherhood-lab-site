# Project pages

Standalone pages for each Tokyo Brotherhood Lab project.

- `whats-next.html` - What's Next overview, screenshot gallery, roadmap and bug-report links
- `whats-next/releases.html` - APK release list with search, filters and sorting
- `whats-next/installation.html` - Android installation and update guide
- `tokyo-manga-lab.html` - Tokyo Manga Lab overview

Shared styles live in `../assets/css/style.css`; shared scripts in `../assets/js/`.
See the root `README.md` for how the data files drive these pages.
