Tokyo Manga Lab

A local-first manga discovery and library app. Search MangaDex, keep your own library on your device, read chapters in the in-app reader, and optionally sync with AniList. Your manga. Your world.

Project information

Find it. Keep it. Read it.

Tokyo Manga Lab searches MangaDex and keeps your library, progress and settings on your own device. No Tokyo Manga Lab account is needed. It is an independent project and is not affiliated with MangaDex or AniList.

✦

What you can do

  • Search and discover: search MangaDex and open a title's details and chapter list, with a chapter-language setting.
  • Build a library: add titles, set a status, mark favourites and group titles into collections. It is all stored on your device.
  • Read in the app: vertical, right-to-left or left-to-right reading, a page slider, resume where you stopped, auto read and more reader options.
  • Sync with AniList (optional): import your AniList manga list and save status changes back. The app works fully without it.
  • Keep a backup: export your library to a file and import it again; importing keeps whichever copy is newer.
  • Use it anywhere: open it in a browser, add it to your home screen as a web app, or install the Android APK.

Good to know: MangaDex is the only manga source, and chapter pages load directly from MangaDex. The app does not download, store or re-host them, and offline chapter downloads aren't available. There is no cloud sync, so backups are files you save yourself. If the project's API service is unavailable or out of date, the app says so and links to the chapter on MangaDex instead. Adult-rated titles are hidden by default; they can only be switched on in the Android app, with a confirmation, and the web version never receives them.
Android & web

Install it on your phone.

The web app works in any modern browser. The Android app is the same app wrapped with Capacitor, built by the project's GitHub Actions workflow.

▤

Android APK

  1. Get the APK from the project's GitHub releases ↗. Builds are also available from runs of the Build Android APK workflow in the repository's Actions tab (a GitHub account is needed there, and the download is a ZIP that contains the APK).
  2. Tap the APK. When Android asks, allow Install unknown apps for the app you opened it with (your browser or file manager).
  3. Install it and open Tokyo Manga Lab.

Before you install: download only from the official project links on this page. The APK is debug-signed, which suits installing on your own phone but not Google Play. Android only installs an update over an existing app when both builds were signed with the same key. If Android reports a conflict, export a backup from inside the app first, then uninstall and reinstall. Uninstalling removes the app's local data.

Bugs & feedback

Found a bug? Let me know.

Bug reports and suggestions are handled on GitHub, so there is nothing to sign up for on this website (a free GitHub account is needed to post). The bug-report button opens a new issue with a ready-made template that asks for:

  • The app version or APK file name
  • Your device model and Android version (or browser, for the web app)
  • A description of the problem and the steps to reproduce it
  • What you expected to happen and what actually happened
